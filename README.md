# TakuGame 🏎️

拓実が作ったブラウザで遊べるレースゲームアプリです。

## 遊び方

`race.html` をブラウザで開くだけですぐに遊べます。

### 操作方法

| キー | アクション |
|------|-----------|
| `↑` | 加速 |
| `← →` | 左右に移動 |
| `R` | リスタート |

### ゲームの目的

道路を走りながら岩などの障害物を避け、できるだけ高いスコアを目指そう！

### パワーアップ

道中に現れる **？ブロック** に触れるとランダムでパワーアップが発動します。

| パワーアップ | 効果 |
|-------------|------|
| 🛞 BIG TIRES | タイヤが大きくなる |
| 🪽 WINGS | 横移動が速くなる |
| ⚡ SPEED UP | 最高速度が大幅アップ |

### スコアシステム

- スピードが速いほどスコアが早く増える
- 走るほど難易度が上がり、障害物の出現間隔が短くなる

## 実行環境

インストール不要。ブラウザ（Chrome / Firefox / Safari など）があればすぐ遊べます。
